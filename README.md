# Devilish AI (😈)

A free, open-source AI assistant with a devilish streak. Unlimited chat with a free account.

**Live:** https://oculoplasty.app

## What it is

- A general-purpose AI chat with a blunt, witty, dark-humored personality
- Free forever for every account - no premium tier, no credit card
- Runs entirely on Cloudflare Workers + Workers AI (zero per-token billing)
- `app.html` in this repo is the live homepage

## Self-host

1. `wrangler kv namespace create COPPUS_CACHE`
2. Bind the namespace and an AI binding in `wrangler.toml`
3. `wrangler deploy`
